# Necromancy

**A complete expansion of the Necromancer role for Hytale.**

Necromancy is a Hytale mod that transforms undead summoning into a complete strategic gameplay system centered around soul manipulation, army building, and ritual-based progression while remaining faithful to Hytale's sandbox philosophy.

## Status

Necromancy is currently in early development and prototyping.

The project is being developed iteratively, with a focus on combat design, implementation, testing, balance, and refinement.
